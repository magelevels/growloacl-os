Privacy

This page describes the current GrowLocal prototype. The public site does not currently operate user accounts, payment processing, cloud client storage or external AI integrations.

Demo workspace data

Information entered into the live demo is stored locally in your browser using browser storage. It is not designed for confidential, sensitive or production customer information. Clearing site data in your browser can remove it.

Analytics and third parties

No third-party marketing analytics are intentionally configured in this release. The site is hosted on Cloudflare infrastructure, so standard network and security logs may be processed by the hosting provider as part of delivering the service.

Future services

If GrowLocal later adds accounts, payments, analytics, CRM integrations or AI services, this notice should be updated before those features are used with customer data.

Questions

Before commercial launch, GrowLocal should add a dedicated business contact address and company/legal details to this notice.
